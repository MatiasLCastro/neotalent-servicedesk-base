name: clasificar-ticket
description: Handle a pasted "Clasifica el ticket ..." prompt from the Mini Service Desk app's "Clasificar con Claude Code" button — assigns prioridad/categoria to one ticket in data/tickets.json. Use whenever the user pastes text generated by Utils.generarPromptClasificacion (starts with "Clasifica el ticket <ID> del Mini Service Desk.").
---

Este skill implementa el contrato exacto de la Feature 2 de `docs/spec.md` (clasificación
asistida por Claude Code). Un prompt pegado por el usuario trae el id del ticket, título,
descripción, sistema afectado y zona — generado por `js/utils/prompt.js`.

## Pasos

1. Extraé el `id` del ticket del prompt pegado (formato `SVD-XXXX`).
2. Buscá ese ticket en `data/tickets.json` por `id`. Si no existe, decíselo al usuario y parate
   — no inventes un ticket ni edites el archivo.
3. Elegí exactamente un valor de cada lista (nunca inventes uno nuevo, nunca dejes vacío):
   - `prioridad`: `Crítica`, `Alta`, `Media`, o `Baja`.
   - `categoria`: `Control de accesos`, `SailPoint (identidades)`, `Centralita de guardia`,
     `Central de alarmas`, `App de rondas`, o `CCTV / videovigilancia`.
4. Reescribí `data/tickets.json` agregando (o reemplazando) esos dos campos **solo** en el
   objeto de ese ticket. No toques ningún otro campo del ticket, ningún otro ticket, ni el
   formato/orden del resto del archivo.
5. Confirmá al usuario en una línea qué prioridad/categoría asignaste y por qué (referenciando
   el título/descripción del ticket) — así puede refrescar la app con "Actualizar datos" para
   ver el cambio (Feature 2, criterio de aceptación de `docs/spec.md`).

Si el ticket ya tenía `prioridad`/`categoria`, preguntá antes de sobreescribir — la UI no
debería ofrecer el botón para un ticket ya clasificado, así que esto sugiere que el usuario
quiere reclasificar a propósito.
